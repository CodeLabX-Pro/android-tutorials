# Jetpack Compose for Beginners (Kotlin)

Your first Compose app: composables and previews, Column and Row, a tap counter with state, a name box, and a second screen with Navigation Compose.

- Video: https://www.youtube.com/watch?v=iQREkIiHYWc
- Step-by-step guide: https://codelab-x.com/videos/iQREkIiHYWc

## Run it

Open this folder in Android Studio and press **Run**.

Built with Android Gradle Plugin 9.4.1, Kotlin 2.4.21, Compose BOM 2026.09.00, Navigation 2.10.2, compileSdk 37, minSdk 24.
