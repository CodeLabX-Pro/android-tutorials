# CodeLabX Android tutorials

Complete Android Studio projects for the [CodeLabX YouTube channel](https://www.youtube.com/@codeLabX-pro?sub_confirmation=1).
Each folder is one tutorial: download its ZIP, open the folder in Android Studio, and press **Run**.

Step-by-step guides live on [codelab-x.com](https://codelab-x.com).

| Tutorial | Video | Guide | Download |
|---|---|---|---|
| [Login and Register with SQLite](login-register-sqlite) | [Watch](https://www.youtube.com/watch?v=8obgNNlj3Eo) | [Read](https://codelab-x.com/videos/8obgNNlj3Eo) | [ZIP](https://github.com/CodeLabX-Pro/android-tutorials/releases/download/downloads/login-register-sqlite.zip) |
| [SQLite CRUD](sqlite-crud) | [Watch](https://www.youtube.com/watch?v=9t8VVWebRFM) | [Read](https://codelab-x.com/videos/9t8VVWebRFM) | [ZIP](https://github.com/CodeLabX-Pro/android-tutorials/releases/download/downloads/sqlite-crud.zip) |

Every project is built with the current stable Android Gradle Plugin before it is published.
