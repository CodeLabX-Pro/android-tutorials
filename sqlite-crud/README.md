# SQLite CRUD in Android Studio (Java)

Insert, update, delete and view records in a local SQLite database.

- Video: https://www.youtube.com/watch?v=9t8VVWebRFM
- Step-by-step guide: https://codelab-x.com/videos/9t8VVWebRFM

## Run it

1. Open this folder in Android Studio.
2. Let Gradle sync finish.
3. Press **Run** on an emulator or phone.

Built with Android Gradle Plugin 9.4, compileSdk 37, minSdk 24, Java 11.
