# RecyclerView with SQLite (Java)

Save users to SQLite and show them in a RecyclerView of cards, with a delete button on each card.

- Video: https://www.youtube.com/watch?v=6enCz2cY18c
- Step-by-step guide: https://codelab-x.com/videos/6enCz2cY18c

Open this folder in Android Studio and press **Run**.

Built with Android Gradle Plugin 9.4.1, compileSdk 37, minSdk 24, Java 11.
