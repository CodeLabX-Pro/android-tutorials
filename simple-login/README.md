# Simple Login App (Java)

A first login screen with a Material design: floating labels, a show/hide password toggle and inline errors.

- Video: https://www.youtube.com/watch?v=K5DWzHZZGB8
- Step-by-step guide: https://codelab-x.com/videos/K5DWzHZZGB8

Log in with username `user` and password `123456`.

Built with Android Gradle Plugin 9.4.1, compileSdk 37, minSdk 24, Java 11.
