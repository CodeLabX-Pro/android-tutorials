# Fragments in Android Studio (Java)

One screen whose middle swaps between two fragments, with a fade and Back support.

- Video: https://www.youtube.com/watch?v=m-PefJ2CcR8
- Step-by-step guide: https://codelab-x.com/videos/m-PefJ2CcR8

Open this folder in Android Studio and press **Run**.

Built with Android Gradle Plugin 9.4.1, compileSdk 37, minSdk 24, Java 11.
