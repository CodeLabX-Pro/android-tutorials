# Login App in Jetpack Compose with Navigation (Kotlin)

A Compose login form with icons, a show/hide password toggle and error messages, then a dashboard reached with Navigation Compose. Log in with the demo account **user** / **123456**.

- Video: https://www.youtube.com/watch?v=wz34oLZx-6A
- Step-by-step guide: https://codelab-x.com/videos/wz34oLZx-6A

## Run it

Open this folder in Android Studio and press **Run**.

Built with Android Gradle Plugin 9.4.1, Kotlin 2.4.21, Compose BOM 2026.09.00, Navigation 2.10.2, compileSdk 37, minSdk 24.
