# Splash Screen in Android Studio (Java)

The classic splash: show your logo for two seconds, then open the app.

- Videos: https://www.youtube.com/watch?v=RYWMkin2YgQ and https://www.youtube.com/watch?v=MfA6kYdvjO8
- Step-by-step guide: https://codelab-x.com/videos/RYWMkin2YgQ
- Modern version with the SplashScreen API: ../animated-splash-screen

Open this folder in Android Studio and press **Run**.

Built with Android Gradle Plugin 9.4.1, compileSdk 37, minSdk 24, Java 11.
