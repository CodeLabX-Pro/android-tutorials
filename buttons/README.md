# Buttons in Android Studio (Java)

Everything about buttons on one screen: handling taps and long presses, the five Material 3 styles, icons, your own shape and colour, turning a button on and off, and a toggle group.

- Video: https://www.youtube.com/watch?v=UbdrcN6kjRA
- Step-by-step guide: https://codelab-x.com/videos/UbdrcN6kjRA

## Run it

Open this folder in Android Studio and press **Run**.

Built with Android Gradle Plugin 9.4.1, Material 1.14.0, compileSdk 37, minSdk 24, Java 11.
