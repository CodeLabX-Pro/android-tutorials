# Forgot Password with SQLite (Java)

The SQLite login app with "Forgot password?": users answer the security question they set at sign-up, then choose a new password.
Passwords and answers are salted and hashed, never stored as typed.

- Video: https://www.youtube.com/watch?v=jRO0RUztch4
- Step-by-step guide: https://codelab-x.com/videos/jRO0RUztch4
- Builds on: [Login and Register with SQLite](../login-register-sqlite)

## Run it

1. Open this folder in Android Studio.
2. Let Gradle sync finish.
3. Press **Run** on an emulator or phone.

Built with Android Gradle Plugin 9.4.1, compileSdk 37, minSdk 24, Java 11.
