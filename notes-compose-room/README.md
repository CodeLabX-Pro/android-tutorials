# Notes App with Jetpack Compose and Room (Kotlin)

A modern notes app: colourful cards in a staggered grid, live search, pin to top, colour picker, and delete with Undo. Built with Jetpack Compose, Room, ViewModel, StateFlow and Navigation Compose.

- Step-by-step guide: https://codelab-x.com/upcoming/notes-compose-room
- Video: coming soon on [CodeLabX](https://www.youtube.com/@codeLabX-pro?sub_confirmation=1)

Open this folder in Android Studio and press **Run**.

Built with Android Gradle Plugin 9.4.1, Kotlin 2.4.21, Compose BOM 2026.09.00, Room 2.8.5, compileSdk 37, minSdk 24.
