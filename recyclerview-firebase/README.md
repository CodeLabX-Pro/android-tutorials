# RecyclerView with Firebase Realtime Database (Java)

A live list of users from Firebase Realtime Database: add or delete a user and every phone updates instantly.

- Video: https://www.youtube.com/watch?v=p2KmuAO8YsE
- Step-by-step guide: https://codelab-x.com/videos/p2KmuAO8YsE

## Run it

1. Create a Firebase project and add an Android app with the package `com.codingtutorials.recyclerfirebase`.
2. Create a **Realtime Database** (start in test mode while learning).
3. Download `google-services.json` into the `app` folder.
4. Open this folder in Android Studio and press **Run**.

Built with Android Gradle Plugin 9.4.1, Firebase BoM 35.1.0, compileSdk 37, minSdk 24, Java 11.
