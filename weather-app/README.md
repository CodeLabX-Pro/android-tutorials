# Weather App (Java)

Search any city and see its temperature, sky, humidity and wind from OpenWeather. The last city you searched opens next time.

- Video: https://www.youtube.com/watch?v=aL1wGcyyNJc
- Step-by-step guide: https://codelab-x.com/videos/aL1wGcyyNJc

## Run it

1. Create a free account at [openweathermap.org](https://openweathermap.org/api) and copy your API key. New keys can take up to 2 hours to start working.
2. Add this line to `local.properties` in this folder (create the file if needed):

   ```
   OPENWEATHER_API_KEY=your-key-here
   ```

3. Open the folder in Android Studio and press **Run**.

Built with Android Gradle Plugin 9.4.1, OkHttp 5.5.1, compileSdk 37, minSdk 24, Java 11.
