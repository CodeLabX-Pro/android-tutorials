# Google Maps in Android Studio (Java)

A Google Map with markers, a "fly to" button and map styles.

- Video: https://www.youtube.com/watch?v=_gpreGNtNCM
- Step-by-step guide: https://codelab-x.com/videos/_gpreGNtNCM

## Run it

1. Create a Maps SDK for Android key in the Google Cloud console.
2. Add this line to `local.properties` in this folder (create the file if needed):

   ```
   MAPS_API_KEY=your-key-here
   ```

3. Open the folder in Android Studio and press **Run**.

Built with Android Gradle Plugin 9.4.1, Maps SDK 20.1.0, compileSdk 37, minSdk 24, Java 11.
