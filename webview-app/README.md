# Convert a Website into an Android App with WebView (Java)

Show your website inside an Android app: loading bar, Back through pages, outside links opened in the browser.

- Video: https://www.youtube.com/watch?v=zu7P_1hY2NA
- Step-by-step guide: https://codelab-x.com/videos/zu7P_1hY2NA

Change `HOME_URL` in `MainActivity.java` to your own site, then press **Run**.

Built with Android Gradle Plugin 9.4.1, compileSdk 37, minSdk 24, Java 11.
