# Tic Tac Toe (Java)

A two-player Tic Tac Toe game with scores, a highlighted winning line, and a board that survives rotating the phone.

- Video: https://www.youtube.com/watch?v=NyUbptjoqb8
- Step-by-step guide: https://codelab-x.com/videos/NyUbptjoqb8

## Run it

Open this folder in Android Studio and press **Run**.

Built with Android Gradle Plugin 9.4.1, compileSdk 37, minSdk 24, Java 11.
