# Text to PDF and PDF Viewer (Java)

Type a title and some text, turn them into an A4 PDF, read it in a built-in viewer, then share it or save a copy.
Uses only Android's own PdfDocument and PdfRenderer, so there's no PDF library to add.

- Video: https://www.youtube.com/watch?v=4-QZdipq80g
- Step-by-step guide: https://codelab-x.com/videos/4-QZdipq80g

## Run it

Open this folder in Android Studio and press **Run**.

Built with Android Gradle Plugin 9.4.1, compileSdk 37, minSdk 24, Java 11.
