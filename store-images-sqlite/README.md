# Store Images in SQLite (Java)

Pick a photo, shrink it, save it into SQLite as a BLOB, and show saved photos in a grid.

- Video: https://www.youtube.com/watch?v=v54dyccVZn0
- Step-by-step guide: https://codelab-x.com/videos/v54dyccVZn0

Open this folder in Android Studio and press **Run**.

Built with Android Gradle Plugin 9.4.1, compileSdk 37, minSdk 24, Java 11.
