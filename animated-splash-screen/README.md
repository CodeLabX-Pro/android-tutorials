# Animated Splash Screen with the SplashScreen API (Java)

The modern splash: an animated icon, kept on screen while the app loads, then animated away. No separate splash activity.

- Video: https://www.youtube.com/watch?v=kt4Z-icG68g
- Step-by-step guide: https://codelab-x.com/videos/kt4Z-icG68g

Open this folder in Android Studio and press **Run**. To see the full splash, close the app and reopen it from the launcher.

Built with Android Gradle Plugin 9.4.1, core-splashscreen 1.2.0, compileSdk 37, minSdk 24, Java 11.
