# Login and Register with SQLite (Java)

Register users, log in and log out, with users stored in a local SQLite database.
Passwords are salted and hashed, never stored as typed.

- Videos: https://www.youtube.com/watch?v=8obgNNlj3Eo and https://www.youtube.com/watch?v=LMD_lQM09po
- Step-by-step guide: https://codelab-x.com/videos/8obgNNlj3Eo

## Run it

1. Open this folder in Android Studio.
2. Let Gradle sync finish.
3. Press **Run** on an emulator or phone.

Built with Android Gradle Plugin 9.4.1, compileSdk 37, minSdk 24, Java 11.
