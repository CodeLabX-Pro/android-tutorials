# Camera App in Android Studio (Java)

Take a full-resolution photo with the phone camera, show it, and share it.

- Video: https://www.youtube.com/watch?v=59taMJThsFU
- Step-by-step guide: https://codelab-x.com/videos/59taMJThsFU

Open this folder in Android Studio and press **Run** on a phone (most emulators have a virtual camera too).

Built with Android Gradle Plugin 9.4.1, compileSdk 37, minSdk 24, Java 11.
