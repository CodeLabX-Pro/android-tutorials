# Login and Registration with Firebase Authentication (Java)

Register, log in, reset a password and log out with email and password, using Firebase Authentication.

- Video: https://www.youtube.com/watch?v=N-nari5HbLk
- Step-by-step guide: https://codelab-x.com/videos/N-nari5HbLk

## Run it

1. Create a project in the Firebase console and add an Android app with the package `com.example.firebaselogin`.
2. Turn on **Authentication → Sign-in method → Email/Password**.
3. Download `google-services.json` and put it in the `app` folder.
4. Open this folder in Android Studio and press **Run**.

Built with Android Gradle Plugin 9.4.1, Firebase BoM 35.1.0, compileSdk 37, minSdk 24, Java 11.
